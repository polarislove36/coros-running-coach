# Intake Questions

Ask only what is needed. Prefer one compact block of questions before creating a full plan.

For COROS users, read available COROS MCP data before asking. Do not ask for recovery, HRV, sleep, training load, daily activity, schedule, or other data available through COROS tools. Only ask for subjective goals, constraints, pain/injury, and fields the current COROS MCP does not expose.

## Minimal Questions

Use these when no COROS data is available or when creating a new plan:

1. 目标比赛是什么？日期、距离。
2. 你的目标是什么？完赛、PB、目标时间、减脂、基础期、伤后恢复。
3. 最近 4 周平均每周跑量或训练时长是多少？最长一次跑了多远/多久？
4. 目前 PB 或最近成绩：5K、10K、半马、全马都可以。
5. 一周能训练几天？每次大概多长时间？哪几天适合长距离？
6. 是否需要安排交叉训练？如果需要，偏好或可用项目是什么：游泳、自行车、椭圆机、划船、步行、瑜伽/普拉提、健身房力量。
7. 可用环境：户外跑、跑步机、操场、健身房、游泳、自行车、椭圆机、步行。
8. 当前是否有伤痛、疲劳、睡眠问题、感冒或医生限制？
9. 力量训练经验如何？能否做深蹲、硬拉、弓步、提踵、核心？

## Helpful Optional Questions

- 平时轻松跑配速/心率大概是多少？
- 是否按心率区间训练？最大心率或阈值心率是否可靠？
- 是否有体重、热适应、补给、胃肠问题？
- 是否偏好晨跑/夜跑？
- 是否需要安排游泳或健身房作为交叉训练？
- 是否长期只能跑跑步机、操场，或有其他训练环境限制？

## Interpreting Runner Shorthand

- For marathon or half-marathon PBs, runner shorthand like `357` usually means `3:57`, and `330` usually means `3:30`.
- Confirm only when the meaning is ambiguous.
- Convert target times into average race pace when useful.

## When User Wants a Short Plan

For a 1-7 day plan, do not require every PB. Ask only for race date, current fatigue/pain, recent long run, and training availability if COROS data is missing.
