常见问题

TrainPilot 只提供训练建议，不承诺医疗诊断或比赛成绩。

支持哪些设备？

首批支持高驰，后续将申请接入佳明等更多平台。

会读取哪些数据？

训练记录、心率区间、HRV、静息心率、睡眠和恢复状态等可授权数据。

可以没有目标赛事吗？

可以。系统也能围绕健康、能力建设或日常训练进行安排。

可以导出计划吗？

计划支持导出为表格、图片，并准备同步到日历。
